# UC Faculty Wage Transparency Dashboard

Interactive dashboard for the paper *Wage Transparency and Within-Rank Salary
Compression: Evidence from UC Faculty Compensation, 2012-2024*
(Kenworthy, Bhattacharya, Wurzer).

## Local setup

**1. Install dependencies** (Python 3.11+ recommended):

```bash
pip install -r requirements.txt
```

**2. Build the pre-aggregated data files** (one-time, requires the raw
`professors/` CSVs):

```bash
python scripts/build_aggregates.py
```

This writes four Parquet files to `dashboard/data/`. They are already
committed to the repository, so this step is only needed if you modify
the aggregation logic or replace the raw data.

**3. Run the dashboard** from the project root:

```bash
streamlit run dashboard/app.py
```

The app opens at `http://localhost:8501`.

## Streamlit Community Cloud deployment

1. Push the repository to GitHub (ensure `dashboard/data/*.parquet`,
   `dashboard/app.py`, and `requirements.txt` are all committed).
2. Go to [share.streamlit.io](https://share.streamlit.io) and click
   **New app**.
3. Set:
   - **Repository**: your GitHub repo URL
   - **Branch**: `main`
   - **Main file path**: `dashboard/app.py`
4. Click **Deploy**. Streamlit Community Cloud installs dependencies
   from `requirements.txt` automatically.
5. The PDF download button reads `paper.pdf` from the repo root.
   Confirm it is committed and not in `.gitignore`.

## Data files

All dashboard data lives in `dashboard/data/` and is committed to git.
The raw CSVs in `professors/` are excluded by `.gitignore` and are not
needed to run the dashboard.

| File | Rows | Description |
|---|---|---|
| `rank_year_summary.parquet` | 65 | CV, mean, median, percentiles by rank x year |
| `rank_campus_year_summary.parquet` | 562 | Same statistics by rank x campus x year |
| `salary_distribution_bins.parquet` | 27,850 | Pre-binned histograms (50 bins) by rank x campus x year |
| `did_estimates.parquet` | 38 | Regression coefficients, HC1 SE, CI for baseline and DiD specs |

## Regenerating figures in paper.tex

Figures are generated by `export_figures.py` (run from the project root).
They are written to `figures/`, which is excluded from git. The dashboard
and the paper use the same underlying data pipeline.
